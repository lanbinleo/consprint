## 读完两份笔记后发现的问题（需要你拍板）

1. **Perceptual set 与 Mental set 在你笔记里都叫「思维定势」**（OPML 2.1 和 2.2）。本表暂定：Perceptual set=知觉定势（先入为主，本身无好坏），Mental set=思维定势（固守旧方法，偏负面）。你也可以两个都保留「思维定势」，但卡片上需要加区分提示。
2. **OPML 4.6 的「自我决定理论」写的是诱因理论的内容**（强调 Incentive），合订本是对的（自主感/胜任感/归属感）。后续内容修订以合订本为准，OPML 那段建议改。
3. **OPML 2.1 把 Perception 写成「直觉」**，应为「知觉」（笔误）。
4. **李克特**：OPML 写「里克特」、合订本写「李克特」，本表统一用「李克特」。
5. **Narcolepsy**：合订本例子里叫「嗜睡症」，本表用标准名「发作性睡病（嗜睡症）」。
6. **Accommodation 一词两义**：U1=晶状体调节，U2/U3=皮亚杰的顺应（你笔记自己也标了「别忘了Piaget」）。已在 U1 条目上加 ⚠。
